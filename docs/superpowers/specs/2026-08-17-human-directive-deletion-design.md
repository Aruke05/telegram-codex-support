# 人工规则永久删除设计

## 背景与目标

`AI 记忆库 → 固定规则` 当前只支持新增、编辑和启停。临时人工规则失效后只能停用，仍会留在规则列表中。

本次增加人工规则永久删除能力，并在功能可用后删除以下两条临时规则：

- `TataPay 本次代理返佣异常临时处理`
- `NupaPay 本次代理返佣异常临时处理`

删除只移除可参与规则检索的 `directives` 记录。已有追加式原始证据和新的删除审计事件继续保留，不能修改或硬删除。

## 删除边界

- 只允许删除 `source = 'human'` 的人工规则。
- `source = 'system'` 的系统固定规则继续由数据库触发器和服务层双重锁定，任何删除请求都必须失败。
- 删除是永久操作，成功后规则不再出现在固定规则列表、回答检索或迁移库的人工规则集合中。
- 删除不级联清理 `memory_events`；规则创建、编辑、启停记录及本次删除事件均保留，满足追加式审计要求。
- 不增加 `deleted_at`、回收站或恢复功能。

## 后端设计

### 服务层

在 `RuntimeKnowledgeService` 增加 `deleteDirective(id, actor)`：

1. 按 ID 读取规则；不存在时抛出“固定规则不存在”。
2. 若来源为 `system`，抛出“系统固定规则不能删除”。
3. 清洗操作者名称，空值使用“后台管理员”。
4. 在一个 SQLite 事务中：
   - 追加 `retraction` 类型的 `memory_events` 事件，内容明确记录被删除规则的标题，范围沿用原规则；
   - 执行带 `id` 和 `source = 'human'` 条件的 `DELETE FROM directives`；
   - 校验实际删除一行，否则回滚；
   - 递增 `memory_generation`，使现有检索缓存失效。

服务返回 `void`，避免删除后继续回传已不存在的规则对象。

### HTTP API

在运行管理路由增加：

```text
DELETE /api/directives/:id
Content-Type: application/json

{ "actor": "后台管理员" }
```

- 成功返回 `204 No Content`。
- 缺少操作者、规则不存在或系统规则删除请求沿用现有统一错误处理，返回中文错误。
- 路由不支持按标题批量删除，避免误删同名或相近规则。

## 前端设计

- API 客户端增加 `deleteDirective(id)`，固定传入后台操作者。
- 每张人工规则卡片增加危险样式的“删除规则”按钮；系统规则仍只显示“系统锁定”。
- 点击删除按钮先打开确认弹窗，标题为“删除人工规则”，正文显示将被删除的规则标题，并明确说明删除后不能恢复。
- 弹窗包含“取消”和危险样式的“确认删除”。确认期间按钮进入忙碌状态，防止重复提交。
- 删除成功后关闭弹窗、显示“规则已删除”，并重新读取固定规则列表。
- 请求失败时弹窗保持打开并展示错误，规则卡片不从页面提前移除。

## 数据流与一致性

```text
人工确认删除
  → DELETE /api/directives/:id
  → 校验人工规则
  → 同一事务追加删除审计 + 删除规则 + 递增 generation
  → 204
  → 前端刷新列表
```

审计事件先于规则删除写入但与删除处于同一事务；任何一步失败都会整体回滚。回答任务只读取已启用且仍存在的规则，因此删除成功后不会再召回该规则。

## 测试与验收

### 服务与 API

- 人工规则可被永久删除，删除后按 ID 和列表都无法读取。
- 删除会新增一条 `retraction` 审计事件，事件包含规则标题、范围和操作者。
- 删除会递增 `memory_generation`。
- 系统固定规则删除失败且记录仍存在。
- 不存在的规则删除失败。
- API 成功返回 204；无效请求返回中文错误。

### 前端

- 人工规则显示“删除规则”，系统规则不显示删除入口。
- 点击删除先出现含规则标题的二次确认弹窗。
- 取消不会发请求。
- 确认只发送一次 DELETE；成功后刷新列表并提示“规则已删除”。
- 失败时保留弹窗并显示错误。

### 上线后数据操作

使用新功能分别删除 TataPay 和 NupaPay 两条临时人工规则。重新刷新固定规则列表，确认两个精确标题均不存在；同时确认其删除审计事件仍可查询。

## 非目标

- 不删除 AI 记忆版本、人工纠正、学习观察或客服记录。
- 不提供批量删除。
- 不允许删除系统固定规则。
- 不清理历史证据，不改变导入导出对其他数据的行为。
