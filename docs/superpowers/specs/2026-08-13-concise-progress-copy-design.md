# 简短进度提示文案设计

## 目标

回答生成超过三分钟且问题仍处于当前生成版本时，固定回复两个字：

```text
稍等
```

不再使用“正在排查 请稍等”，不随机选择文案，不模拟打字错误，不发送单独表情，也不给原消息添加表情回应。

## 实现范围

- 只修改三分钟进度提示的固定文案。
- 保留现有 `humanizeOperatorAnswer`、Telegram reply、output ownership、notification claim、发送超时和完成状态链路。
- 保留同一问题版本只创建一条进度通知的现有去重语义。
- 真正达到回答运行上限或一小时硬截止时继续使用现有诚实超时兜底。
- 不新增配置、接口、数据库结构或依赖。

## 测试与验证

按测试驱动方式覆盖三分钟进度通知发送的正文严格等于 `稍等`，并确认回复目标和 output ownership 保持不变。
